# 📘 Wordz App

Wordz App is a vocabulary learning application that allows users to **create, manage, and memorize English vocabulary** through CRUD features and an **interactive quiz game** based entirely on words added by the user.

The app is designed with one main goal: **to help users truly remember new vocabulary**, not just store it.

---

## 🎯 Purpose

* Help users store newly learned English vocabulary in a personal way
* Encourage consistent learning and long-term memory
* Turn vocabulary learning into an **active and enjoyable experience** through quizzes

---

## ✨ Key Features

### 1️⃣ Vocabulary Management (CRUD)

Users can:

* ➕ **Add new English words** along with their meanings
* 👀 **View a list of saved vocabulary**
* ✏️ **Edit words or meanings** when needed
* 🗑️ **Delete vocabulary** that is no longer relevant

All vocabulary is **custom and personal**, based on words the user actually wants to learn.

---

### 2️⃣ Quiz Game (Vocabulary Quiz)

The quiz feature is generated **entirely from the user’s own vocabulary list**, not from predefined system data.

Quiz examples:

* Choose the correct meaning of a word
* Guess the correct word based on its meaning
* Score tracking to encourage consistency and motivation

Quiz goals:

* Test memory retention
* Strengthen long-term recall
* Make vocabulary learning feel like a game rather than memorization

---

## 🧠 Why Wordz App?

❌ Many vocabulary apps rely on generic word lists

✅ Wordz App focuses on:

* Words you **actually encounter** (books, songs, movies, coding docs, etc.)
* Personalized learning instead of one-size-fits-all content
* **Active recall**, not passive reading

With Wordz App, every word goes through this process:

> Save → Learn → Test → Remember
